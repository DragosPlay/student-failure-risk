# Прогнозирование риска академической неуспеваемости (Кейс: «Кто не получит зачёт»)

Реализация воспроизводимого пайплайна машинного обучения для бинарной классификации студентов из группы академического риска на основе демографических и поведенческих факторов (`student-por.csv`, `student-mat.csv`).

## 📌 Ключевые результаты

В рамках кейса разработаны и сопоставлены два уровня предиктивных моделей:

1. **Уровень 1 (Базовый):** использует все доступные данные, включая промежуточные контрольные ($G1, G2$).
   * Оценка качества на кросс-валидации (5-fold Stratified CV): **ROC-AUC ~ 0.97**.
   * Основные драйверы: оценки за первую и вторую четверти ($G1, G2$).
2. **Уровень 2 (Раннее предупреждение):** исключает промежуточные оценки, прогнозируя успеваемость в начале семестра.
   * Оценка качества на кросс-валидации (5-fold Stratified CV): **ROC-AUC ~ 0.82**.
   * Топ-3 фактора риска (SHAP-анализ на всех фолдах): учебное заведение (`school`), число прошлых провалов (`failures`), пропуски занятий (`absences`).

### Перенос на другой домен (Domain Transfer)
Проверка модели раннего предупреждения без дообучения на курсе математики (`student-mat.csv`) показала просадку метрики ROC-AUC до **~0.65**. Это демонстрирует, что факторы риска академического провала предметно-специфичны: модель раннего предупреждения требует калибровки под конкретную дисциплину.

## 🚀 Интерактивный дашборд и API (Система раннего предупреждения)

На базе модели **Уровня 2** реализовано веб-приложение `app.py` для практического использования результатов прогнозирования. Для классификации используется откалиброванный порог вероятности `0.1304`.

* **Веб-интерфейс (`GET /`):** Приложение содержит визуальный HTML-дашборд для ручного ввода всех 30 параметров студента. В интерфейс встроены кнопки быстрых сценариев («Благополучный профиль» и «Критический риск») для моментальной проверки работы алгоритма.
* **REST API (`POST /predict`):** Эндпоинт принимает данные студента в формате JSON, прогоняет их через ансамбль обученных моделей и возвращает итоговую вероятность несдачи, флаг попадания в группу риска и текстовую рекомендацию (например, *"Срочно пригласить на беседу с куратором"*).

## 🛠 Стек технологий

* **Python 3.12**
* **CatBoostClassifier** — градиентный бустинг с нативной поддержкой категориальных фичей.
* **Scikit-learn** — стратифицированная валидация (`StratifiedKFold`), калибровка вероятностей (`IsotonicRegression`), расчет метрик.
* **SHAP** — анализ важности и стабильности признаков.
* **Pandas / NumPy / Seaborn / Matplotlib** — предобработка данных, EDA и визуализация.
* **FastAPI & Pydantic** — развертывание REST API, маршрутизация и строгая валидация входящих типов данных.
* **Joblib** — сохранение и загрузка обученного ансамбля моделей (`models_l2.joblib`) и калибратора (`calibrator_l2.joblib`).
